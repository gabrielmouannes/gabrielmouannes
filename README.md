## 📂 Featured Projects

### 🤖 Robotic Arm & Conveyor Automation System

A small-scale industrial automation project combining **robotics, computer vision, embedded computing, and mechanical design**.

The system uses a **Raspberry Pi and OpenCV** to identify products moving through a conveyor system and sort them into designated locations using a robotic arm.

**Focus areas:**

* Computer vision
* Object detection and classification
* Robotic arm control
* Mechanical CAD design
* Automation and system integration

---

### 🏫 Smart Classroom Attendance System

A hardware-based attendance system developed for **Logic Design Lab** using discrete digital logic.

The prototype was built using **47 74LS-series logic ICs**, with the physical circuit designed and tested alongside simulations in **Intel Quartus Prime**.

My main contribution involved developing the **10-to-0 countdown logic module** and debugging timing behavior between the simulated design and the physical breadboard implementation.

**Technologies:** Intel Quartus Prime · 74LS ICs · Digital Logic · Breadboard Prototyping

---

### ❤️ Heart Pulse Monitoring System

An analog electronics project designed to extract and visualize cardiac pulse signals from an optical sensor.

The circuit uses **multiple operational-amplifier stages and active band-pass filtering** to amplify the desired signal while reducing unwanted noise.

**Focus areas:**

* Analog circuit design
* Operational amplifiers
* Active filtering
* Signal conditioning
* Proteus simulation

---

### 🅿️ Arduino Parking Simulator

A sensor-driven smart parking system developed around an **Arduino-based state machine**.

The system simulates parking-space management, handling vehicle entry, exit, and available-space tracking based on sensor inputs.

**Technologies:** Arduino · Sensors · State Machines · TinkerCAD

---

### ⚙️ V12 Engine CAD Model

A personal CAD project focused on developing a complete **V12 engine assembly in SolidWorks**.

The project involved modeling and assembling the individual mechanical components while learning how complex assemblies are structured and constrained in a professional CAD environment.

**Technologies:** SolidWorks · Mechanical CAD · Assembly Design
